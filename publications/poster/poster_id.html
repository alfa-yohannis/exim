Building Your Own Local AI

Empower your organization's document search with AI

Tanya apa saja soal dokumen akreditasi, pakai bahasa sehari-hari. Jawabannya selalu menyebutkan nama file dan halaman sumbernya, dan dokumen itu bisa langsung Anda buka.

Masalahnya

  • — Bukti akreditasi tersebar di ribuan file pada shared drive: PDF, Word, Excel, paparan, sampai hasil pindaian.
  • — Satu pertanyaan asesor bisa menghabiskan setengah jam hanya untuk membuka file satu per satu.

Cara kerjanya

1
Anda mengetik pertanyaan dalam Bahasa Indonesia.
2
Sistem mencari dokumen-dokumen yang paling relevan dan merangkumnya untuk Anda.
3
Sistem menampilkan kartu bukti: nama dokumen, halaman, dan kutipannya. Sekali klik, file aslinya terbuka atau terunduh.

Contoh tampilan jawaban. Kartu buktinya tinggal diklik untuk membuka file aslinya.

Mengapa jawabannya bisa dipercaya

  • ✓ Bisa langsung dicek. Tiap kalimat ada nomor sumbernya, dan dokumennya bisa dibuka saat itu juga.
  • ✓ Tidak mengarang. Jawaban disusun dari isi dokumen. Kalau tidak ada di arsip, sistem menjawab tidak ditemukan.
  • ✓ Dokumen aslinya aman. Sistem hanya membaca file di shared drive, tidak pernah mengubahnya.
  • ✓ Data tetap di kantor. Semua proses berjalan di komputer milik prodi sendiri.

Publik — ChatGPT, Gemini, atau Claude, bila ingin jawaban yang lebih tajam.
